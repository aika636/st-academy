# Шрифты

Файлы в `files/` взяты из Google Fonts (только кириллица и латиница). Все семейства
распространяются по лицензии SIL Open Font License 1.1:
https://openfontlicense.org/open-font-license-official-text/

Семейства: Bad Script, Caveat, Cormorant Garamond, Exo 2, Golos Text, IBM Plex Mono,
IBM Plex Sans, IBM Plex Sans Condensed, Literata, Lora, Neucha, Nunito, Oswald,
Playfair Display, PT Sans, PT Serif, Rubik, Russo One. Авторские права — у авторов каждого
семейства.
