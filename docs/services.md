# Служебные запросы, ключи и портреты

## «API для генерации» (`api.js`)

Служебные запросы расширения — учебный план, автозаполнение анкеты, секретарь, каст и выпуск слухов, слова мира, поиск людей в книгах мира и в каноне — идут через блок «API для генерации» (панель → «Настройки», копия в меню расширений). Основные ответы рассказчика сюда не относятся: их пишет сама таверна. Источник — явный выбор из двух:

| Графа | Что это | Ключ |
|---|---|---|
| Актуальный API таверны | подключение, которым таверна отвечает сейчас; при желании конкретный профиль подключения | не нужен |
| Свой адрес с ключом | отдельное OpenAI-совместимое подключение (например, дешёвая служебная модель) | нужен |

- **Актуальный API:** запрос делает сама таверна (через профиль — `ConnectionManagerRequestService`, без профиля — `generateRaw`; `{{` экранируется), расширение ключ никуда не отправляет. Своего списка моделей у такого подключения нет; «Проверить связь» ходит тем же путём, каким пойдёт генерация. Для chat completion пресет в служебный запрос текста не добавляет, только параметры.
- **Свой адрес:** адрес приводится к виду `…/v1/chat/completions` (можно вписать базу, `…/v1` или полный путь). Запрос идёт из браузера с `Authorization: Bearer`. Список моделей запрашивается из браузера, а если не пускает CORS — через сервер таверны (тогда ключ проходит через этот сервер, панель об этом говорит). Генерация на адрес без CORS через таверну не идёт. Ключ чистится от невидимых символов на лету; пробел внутри ключа — ошибка.
- Параметры: для o-серии и новых моделей — `max_completion_tokens` без `temperature`, один повтор на 400 про эти параметры.
- Повторы: ошибки шлюза и 429/5xx — до трёх попыток с паузами 0,8 и 1,6 с; HTTP 200 с телом `Bad Gateway` считается шлюзовой ошибкой; «Проверить связь» не повторяет; `Retry-After` не читается; сетевой сбой и пустой ответ плана не повторяются; пустой ответ шлюза не разбирается. Таймаут запроса 240 с; при тайм-ауте панель советует модель без рассуждений.
- Адрес запроса не показывается ни в одной ошибке (подсказка про `/v1` остаётся).
- Рассуждающие модели могут отдавать рассуждения прямо в `content` и тратить лимит ответа; код срезает утёкшие рассуждения (`core/leak.mjs`), лимиты каста и плана подняты (план — до 16384 для канона, анкета — 4096). Обрыв определяется по отсутствию служебной метки конца, повтор запроса идёт с невидимой меткой, чтобы обойти кэш посредника.
- Устаревший результат (другой чат или эпоха запроса) отбрасывается.

## Ключи

Ключи API (служебные запросы, портреты) лежат **только в `localStorage` этого браузера** (`academy_keys`, `storage.readKey/writeKey`). Они не попадают в настройки таверны, их экспорт, `chat_metadata`, `/academy-state`, отладку и выгрузку состояния; на другом устройстве вводятся заново. Скрипты других расширений работают в той же странице, поэтому надёжнее профиль подключения таверны. Внешняя ссылка портрета загружается с того сайта, где лежит картинка. Хост-API (`setSettings`) защищён от `__proto__`/`constructor`/`prototype`.

## Портреты (`draw.js`, `core/draw.mjs`, `core/draw-prompt.mjs`, `portraits.js`)

- Фото (с телефона или компьютера; только путь или http(s), без `data:`) либо рисунок. Пути рисования: генерация картинок таверны или свой адрес с ключом — OpenAI-совместимый, Gemini/Imagen, роутер-прокси, NovelAI напрямую (`DRAW_ROUTES`). Кнопка «Нарисовать» без доступного пути скрыта.
- Запрос строится из внешности человека (`looks` в плане, записи книги мира — строка «Внешность:», секретарь `looks=`), стиля рисования (до 1000 знаков) и шаблона; без внешности «Нарисовать» придумывает её. Для тегового пути русская внешность переводится в теги отдельным запросом; пол и возраст (граница слова) проверяются; своя одежда главнее шаблона. Во всех запросах — взрослые персонажи.
- Результат кладётся в хранилище таверны.
