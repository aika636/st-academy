# Книга мира, люди и канон

## Люди

- **Наставники и однокурсники** хранятся в состоянии чата; у человека — черты, желание, беда, связи, внешность, портрет, отношение (ярлык), «как менялось». Преподавателей мало, но с ролью: должность, «любит», секрет (в книгу уходит с пометкой «героиня не знает, только намёками»).
- Источники курса: ручное добавление, генерация учебного плана по анкете (`core/plan-gen.mjs`, поле `looks` — короткая внешность под характер, ручную внешность генерация не перетирает), подбор из книги мира («Искать в книгах мира»), канон («Найти в каноне»), предложения секретаря (`new=`, `looks=`).
- Стоп-лист имён (`core/stop-names.mjs`) не пускает в курс служебные слова и имя персонажа игрока; для персонажа карточки — предупреждение, а не молчаливое добавление; сравнение сквозь алфавит и по звучанию (короткие имена).
- Люди из книг игрока попадают в курс только после «Применить» в «Сокурсники». Глобально выбранные книги мира в расширение **не попадают нигде** (план, поиск людей, подсказка анкеты): только книга чата, карточки и встроенная. Правила общие, не под конкретную книгу.
- Подпевалы травли — только недружелюбные из книги / ставшие недружелюбными / сгенерированные недружелюбными; иначе «безымянные приятели».
- Род человека на плашке — по имени (`core/gender.mjs`), не определился — безлично.
- Все персонажи расширения — совершеннолетние.
- Стирающие кнопки подтверждаются вторым нажатием («Нажмите ещё раз»): «Удалить однокурсников», «Удалить человека» в предупреждении о персонаже карточки (человек стирается целиком); «Сохранить внешность» — только если прежнее описание непустое и отличается от нового. Сам хелпер — `tapButton` в `ui/common.js`.

## Канон (фандом)

Поле «Фандом» в анкете включает игру по известному произведению; пусто — свой мир. Если к карточке привязаны книги мира, под полем показаны их названия (нажатие вписывает название).

- **Приоритет:** книга мира > канон > выдумка. В оригинальном мире с лорбуком всё берётся из лорбука; выжимка лорбука идёт и в генерацию плана.
- Канонический блок в генерации плана; у наставников `canon` и `aliases` (перевод — как пишет модель, второе написание в aliases; год канона — из анкеты; события канона — фоном). `canon` без фандома отбрасывается при разборе плана и снимается при загрузке чата.
- **Слова мира** (`core/canon-vocab.mjs`, `canon-layer.mjs`): подбираются после генерации плана и заменяют строки интерфейса, праздники и глоссарий пресета на слова канона («Обновить слова мира» повторяет). Пресет задаёт остальные литералы. Слой хранится в состоянии чата.
- Канонные однокурсники (`core/canon-course.mjs`) ложатся общим списком найденных («Найдено: N»); главных героев канона в однокурсниках оставлять нормально. Статисты ленты — канонические имена.
- Фандомных пресетов нет: фандом модель подтягивает сама из карточки, книги мира и памяти плюс слой канона.
- Известные слабости: модель иногда не ставит `canon` у наставника; алиасы с мусором (иной алфавит) режутся при разборе; широкий лорбук сдвигает план — выбор берёт из лорбука людей, а не чужие миры.

## Книга мира чата (лорбук)

В интерфейсе — «книга мира». Включается в «Книге мира академии» (по умолчанию выключена); ведёт World Info чата: устав, словарь мира, люди, дела травли, живые слухи. Модуль — `lorebook.js` (запись в ST), `core/lorebook.mjs` (состав, диф), `lore-keys.mjs` (ключи), `lore-english.mjs` (перевод), `lore-status.mjs` (тихий статус «обновлён — что изменилось / ждёт / ошибка»).

Правила:
- Запись — функция состояния: «что верно сейчас». Хроники «что было» расширение не ведёт (этим занимаются расширения памяти).
- **Содержимое записей — по-английски**, главные — `{{char}}` / `{{user}}`; перевод моделью один раз при создании или правке, с таблицей написаний; кириллица в «ёлочках» (цитаты, названия) без отказа. Устав и слова мира — английские версии из пресета (`charterEn`, `reputationEn`, `termsEn`).
- **Свои NPC** — по шаблону `[NAME AND BASICS] / [APPEARANCE] / [PERSONALITY] / [RELATIONSHIPS] / [BACKGROUND] / [CURRENT SITUATION]`, только установленное, 150–500 токенов.
- **Люди из книг игрока:** полной записи нет; приписка «ACADEMY CONTINUITY ADDENDUM» на 40–150 токенов — только если есть факты этой истории (предмет, поступки, дела, роль в травле). Нейтральное «не выделяется» — не повод. Человека плана связывают с записью книги игрока (`loreLink`, «Убрать связь»; привязка по ключу с опечаткой).
- **Ключи** — регулярки: английские с границей слова `\b`, русские `(?<![А-Яа-яЁё])основа[А-Яа-яЁё]*`; до 13–15 без добивания; без голых должностей и коротких алиасов; наблюдавшиеся написания добавляются; модель предлагает, код проверяет и отсекает слишком общие. Ключ по названию предмета у экзаменных дел срабатывает не всегда.
- Дела травли — запись `BULLYING HISTORY` без дат; живые слухи — отдельные записи `RUMOR` и `COHORT TALK` с русскими цитатами, без дат и счётчиков; публичное без реплик не кладётся; живут ограниченное число дней (5), выпавшие удаляются; дела между людьми — строкой в записях участников. Высшие оценки в книгу не идут.
- Потолок записей — 60 (50 в магическом пресете); потолок выселяет свою нетронутую запись. Ручные правки игрока (`edited`) и чужие записи (`foreign`) не трогаются.
- **Книга не откатывается свайпом:** тексты записей придут в соответствие при следующей синхронизации, но запись про отменённое событие автоматически не исчезает; такие записи сносятся по решению игрока. Экспорт книги в карточку теряет служебное поле с отпечатком (такая книга считается правленой руками). Удаление человека с курса удаляет его запись и память об отношении.
- Выключатель Академии гасит и возвращает записи книги (`suspendBook`).
- Запоздалая запись после свайпа в книгу не ложится (сверка поколения перед записью).
