# Устройство расширения

Расширение — обычные ES-модули без сборки, доступ к таверне через `SillyTavern.getContext()`, ошибки внутри расширения логируются и не роняют интерфейс. Ниже — устройство самой Academy.

## Слои

- `core/*.mjs` — чистые функции над данными, без DOM и без ST. Тестируются под `node --test`. Почти все правила заведения живут здесь.
- Корень (`index.js`, `storage.js`, `prompt.mjs`, `api.js`, `commands.js`, `lorebook.js`, `draw.js`, `portraits.js`, `mes-panel.js`, `ui.js`) — привязка к таверне: события, хранилище, инжект в промпт, служебные запросы, слэш-команды, книга мира, плашка под ответом.
- `ui/*.js` — вкладки панели и общие виджеты; `style.css`, `diary.css`, `guard.css`, `materials/*.css` — оформление (см. `design.md`).
- `presets/*.json` — одиннадцать заведений: словарь, календарь, шкала оценок, контрольные, праздники, сленг и голоса ленты, материал оформления. В `core/` нет ни одного слова конкретного заведения: если для нового заведения приходится править код, а не данные, абстракция выбрана неверно.
- Публичный API для других расширений: `window.AcademyAPI` (см. README).

## Состояние и хранение

- **Состояние семестра** — `chat_metadata.academy` (ключ в `core/state.mjs`, схема версионируется, `migrate` поднимает старые). У каждого чата свои календарь, оценки, люди, лента. Метаданные чата берутся заново при каждом обращении: ссылка на объект меняется при смене чата.
- **История ходов** — отдельный ключ `chat_metadata.academy_turns`: снимки состояния «до ответа» с общим пулом, глубина 5 ходов. Нужны для свайпа, регенерации и «Отменить ответ». Правка ответа в середине чата ничего не пересчитывает.
- **Настройки** — `extensionSettings.academy`: пресет по умолчанию, источник времени, глубина инжекта, секретарь, лента, оформление, свои пресеты (до 20, до 1 МБ каждый). Растущие поля сразу с пределом (счётчик достижений, автоугадки каста, черновики).
- **Ключи API** — только `localStorage` браузера (`academy_keys`), мигрируются из старых настроек при загрузке. В настройки таверны, состояние чата, экспорт и выгрузку состояния не попадают.
- **Пресет чата:** активным при открытии чата становится `state.presetId`; общая настройка нужна только новым чатам. Предпросмотр оформления другого пресета не меняет пресет чата.

## Поток ответа

1. Ответ модели приходит событием таверны; свайпы, правки и удаления разобраны по событиям.
2. Время: источники по очереди (`time-source`, см. `time-and-marker.md`); календарь двигает движок (`engine`) с посещаемостью, прогулами, наступлением событий.
3. Секретарь (отдельный запрос) читает ответ и реплику игрока, возвращает метки; код применяет их в `engine`/`scene` (см. `secretary.md`).
4. После разбора по расписанию выходит выпуск слухов (`feed.md`), обновляется книга мира (`lorebook-canon.md`), плашка под ответом показывает итог.
5. Перед следующей генерацией `prompt.mjs` собирает инжект.

## Инжект в промпт

Все три позиции `IN_CHAT`, роль system, имена тегов — `academy_scene`, `academy_marker`, `academy_note`:

| Что | Глубина |
|---|---|
| Строка состояния (сегмент сцены) | `injectDepth` (по умолчанию 1) |
| Инструкция про метку | `injectDepth + 1` |
| Одноразовый факт «это только что случилось», повод «Взять в сюжет» | 0 |

- **Текст инжекта — английский**, по-русски остаются только имена, названия предметов, праздников и слова из данных. Русские — журнал, подписи интерфейса, плашка, лента. Это касается и секретаря.
- Если семестр в чате не начат, все три строки пустые: расширение промпт не занимает.
- Строка состояния короткая, с потолком на число чисел (6 в школьных пресетах, 4 в магическом). Расписание молчит ночью, в выходной, на каникулах и после последней пары. Инструкция про метку — около 60 токенов.
- Закрытые знания (оценка, итог которой ещё не объявлен) модель получает как «закрытые сведения симуляции, не знание персонажей».
- Служебные фоновые генерации (quiet) инжект не получают; impersonate получает все инжекты.

## Служебные запросы

Секретарь, учебный план, анкета, каст и выпуск слухов, слова мира, поиск людей — через `api.js` (подробности в `services.md`). Устаревший результат (другой чат, другая эпоха запроса) отбрасывается. Таймаут запроса 240 с.

## Проверка

- `npm test` — `node --test "test/*.test.mjs"`.
- Оформление проверяется на узких ширинах (390 и 360 px) и на теме таверны с собственным CSS.
