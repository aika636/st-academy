# Оформление: ежедневник, материалы, страж

Панель выглядит как ежедневник героини: материал (тетрадь, гримуар, кожаный блокнот, планер, терминал…) меняется с заведением, раскладка та же. На ширине панели от 760 px — разворот из двух страниц, на телефоне и в узкой панели — одна страница; ширина по окну (≥ 1100 → 880, иначе 440). Режим «Цвета таверны» — те же страницы в цветах темы ST.

## Файлы

- `style.css` — база панели (грузится манифестом), `diary.css` — ежедневник (классы с префиксом `dia-`), `materials/<id>.css` — по одному материалу (селекторы скоуплены по `data-mat`), `guard.css` — страж, `fonts/` — шрифты локально (SIL OFL, список `fonts/OFL.md`; внешних запросов за шрифтами нет).
- `materials/index.mjs` — каталог материалов (`MATERIALS`, образцы цветов, чернила, признак шрифтов); `ui/look.js` — включение материала и шрифтов; `ui/emblems.js` — свой герб в шапке у каждого заведения; `ui/icons.js` — значок плавающей кнопки (ежедневник по умолчанию, перо, герб); `ui/spread.js` — разворот.
- Материал заведения задаёт пресет (`look.material`); ручной выбор — в «Оформление». Одиннадцать заведений ↔ одиннадцать материалов, у космической академии есть надстройка «бортовой журнал».

## Правила

- **Цвета только через слой переменных** `--ad-*`, не из `--SmartTheme*` напрямую (тема таверны красит теги, и светлый текст темы протекает на светлую бумагу). Для любых новых элементов — проверка контраста WCAG (текст против первого непрозрачного фона, < 3 — дефект) в живой таверне с её темой.
- **Страж.** Тема таверны может писать `button/input/a/h3/h4 { color … !important }`; обычные правила ей проигрывают. `guard.css` — копия цветовых объявлений `diary.css` и материалов с теми же селекторами, но с `!important` и целиком внутри `@layer academy-guard`: важное внутри слоя бьёт важное вне слоя. После правки цветов в CSS страж пересобирается скриптом `tools/guard-css.mjs` (тест напоминает).
- Разные материалы не должны гасить мотив друг друга: «душа» заведения — иллюстративные SVG-ассеты слоями фона (`background-image` с data-URI, разные для левой и правой страницы), крупный мотив виден без прокрутки; свои особенности материала (цветные вкладки, полоски полок, самоцветы) — часть образа. Мотив решается местом, а не прозрачностью.
- Эталон жанровой выразительности — материал героев; бытовые материалы (школа, вуз) — сдержанные.
- Подписи панели берутся из пресета (слова заведения); корявые, канцелярские, обрезанные подписи и служебные слова в интерфейсе — дефект. Названия вкладок (лента слухов, достижения) тоже из пресета.
- Кнопки, которые стирают данные, подтверждаются вторым нажатием: `tapButton` (`ui/common.js`) — подпись меняется на «Нажмите ещё раз» на 4 с, повтор в первые 0,5 с не считается, состояние хранится по ключу и переживает перерисовку. В `mes-panel.js` — свой `confirmTap` с тем же поведением.
